# horse_club_telegram_bot
Телеграмм-бот для конного клуба

Учебный проект | 2023 год | Python MySQL

## Возможности бота

- Регистрация и авторизация пользователей
- Три вида пользователей - клиент, тренер, администратор
- Запись на занятие (клиент)
- Управление своими записями (клиент)
- Просмотр расписания (клиент)
- Управление расписанием и записями (преподаватель, администратор)
- Управление учетными записями (администратор)
- Архивация базы данных (администратор)
- Восстановление базы данных из архива (администратор)
- Визуализация графиков (администратор)
